# Customer Churn Analysis using Python & Power BI

An end-to-end data analytics project focused on analyzing telecom customer churn, identifying key churn patterns, and presenting business insights through an interactive Power BI dashboard.

## 📌 Project Overview

Customer churn occurs when existing customers stop using a company's products or services. This project analyzes a telecom customer dataset to understand the factors associated with customer churn and identify patterns that can help improve customer retention.

The analysis was performed using **Python** for data cleaning, preprocessing, exploratory data analysis (EDA), and visualization, while **Microsoft Power BI** was used to create an interactive business dashboard.

## 🎯 Objectives

* Clean and preprocess telecom customer data
* Handle missing and inconsistent records
* Perform Exploratory Data Analysis (EDA)
* Analyze customer behavior and churn patterns
* Identify factors associated with customer churn
* Create meaningful visualizations
* Develop an interactive Power BI dashboard
* Calculate important business KPIs
* Generate actionable business insights

## 📊 Analysis Performed

The project analyzes customer churn across several important factors:

* Contract Type vs Churn
* Payment Method vs Churn
* Internet Service vs Churn
* Customer Tenure vs Churn
* Monthly Charges vs Churn

These analyses were used to understand customer behavior and identify patterns related to retention and churn.

## 📈 Power BI Dashboard

The interactive dashboard includes key business KPIs such as:

* **Total Customers**
* **Churned Customers**
* **Churn Rate**
* **Average Monthly Charges**

It also provides visual analysis of contract type, payment method, internet service, tenure, and monthly charges.

## 💡 Key Insights

* Month-to-month contract customers show higher churn compared with customers on longer-term contracts.
* Customer tenure has an important relationship with retention.
* Monthly charges are associated with differences in customer churn behavior.
* Payment methods and internet service categories show different churn patterns.
* Long-term contracts are generally associated with stronger customer retention.
